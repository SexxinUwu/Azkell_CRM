# Reglas del Proyecto

- **Terminología**: Referirse siempre al sistema que estamos construyendo como un **ERP**, no como un CRM.
- **Base de Datos**: La base de datos es **MySQL hosteada directamente en el VPS propio** (no usar ni referenciar Aiven).
- **Stack Actual**: Full-Stack JavaScript (Node.js/Express + JavaScript Vanilla ES6/HTML5/CSS3/Bootstrap 5 + MySQL en VPS).
- **Hoja de Ruta / Planes Futuros**: Migración planificada en un entorno paralelo a React + Tailwind CSS + TypeScript para no afectar producción.
